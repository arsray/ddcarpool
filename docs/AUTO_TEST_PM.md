## M1 剩余手工怎么测（Crystal）

### M1-5 · 我的订单 UI（约 3 分钟）

**准备：** 我的 → 账号与安全 → 切 **Alice**（乘车人种子单）或 **Bob**（车主种子单）。

| 步骤 | 操作 | 看什么 |
|------|------|--------|
| 1 | 我的 → **我的订单**（或乘车人/车主订单入口） | 能进列表 |
| 2 | 若有双身份，切 **乘车人 Tab** / **车主 Tab** | Tab 与身份一致 |
| 3 | 点筛选：**全部 / 未完成 / 已完成 / 已关闭** | 条数变化合理（种子单共 5 态） |
| 4 | 看每条卡片 | 状态 Tag、路线、时间；车主侧**只有「接单」角标**，没有「发布」 |
| 5 | 看第三行小字 | 匹配中「等待…」、待出发有车主/乘客名等 |

**通过标准：** 样式正常、筛选不丢单、角标规则对。

---

### M1-6a · 种子单 detail（约 3 分钟）

**准备：** 仍在 **我的订单** 列表（Alice 或 Bob 均可）。

| 步骤 | 操作 | 看什么 |
|------|------|--------|
| 1 | 点一条 **种子单**（不要点 M3 真实单，没有就只用种子） | 进入 **同一套 detail 页** |
| 2 | 看顶部 | 状态 + 副文案（如「等待车主接单」） |
| 3 | 看内容块 | 出发、路线、人数/备注等 |
| 4 | 看底部按钮 | 匹配中乘客应有 **编辑、取消搭车单**（编辑是 Toast）；已完成乘客有 **再来一单** |
| 5 | 点 **再来一单**（若有） | 应跳到 **发布 Tab** |
| 6 | 点 **进入 Chat**（若有） | Toast 占位即可 |

**通过标准：** 布局正常、按钮和状态对得上种子单，再来一单能跳发布 Tab。
