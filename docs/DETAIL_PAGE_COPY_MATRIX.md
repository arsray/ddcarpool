> **用途**：按 5 种订单状态 × 车主/乘客视角，填写详情页 header 文案与底部 Action CTA。  
> **填好后**：把本文件发给我，我会按表格改 `pages/detail/`。  
> **参考**：「当前实现」列是 main 分支现有逻辑，可改可留。

---

## 填写说明

### Header 三行文案

| 字段 | 位置 | 说明 |
|------|------|------|
| **角色标签** `roleLabel` | 状态栏第一行（小字） | 如「我已接单」「我发布的」「顺路订单」；不需要则填 `-` |
| **状态标题** `statusLabel` | 状态栏第二行（大字） | 通常用状态名：匹配中 / 待出发 / 行程中 / 已完成 / 已关闭 |
| **副标题** `statusHint` | 状态栏第三行（说明） | 一句场景说明；不需要则填 `-` |

### Action CTA

从下方 **可选按钮** 里选，按 **从上到下** 填写顺序（第 1 个 = 最上方主按钮）。

**可选按钮 key**（填 key + 自定义文案；文案留空则用默认）：

| key | 默认文案 | 系统条件（不可改逻辑，只能决定显不显示） |
|-----|----------|------------------------------------------|
| `accept` | 确认接单 | 车主 · `matching` · 从广场进入 · 未接单 |
| `start` | 开始行程 | 车主 · `pending_departure` |
| `complete` | 完成 | 车主 · `pending_departure` 或 `in_progress` |
| `cancel_passenger` | 取消搭车单 | 乘客 · `matching` 或 `pending_departure` |
| `cancel_driver` | 取消匹配 | 车主 · `pending_departure` |
| `chat` | 联系同行人 | 乘客或车主 · `pending_departure` 或 `in_progress` |
| `history` | 查看我的订单 | 乘客；或车主且无完成/取消按钮时 |
| `plaza` | 返回广场 | 从广场进入 · 状态 ≠ `matching` |

**填写格式示例**（CTA 列）：

```
1. complete | 确认送达
2. chat
3. cancel_driver | 放弃本单
—
（无更多按钮则 `-`）
```

> 若某状态下系统**不允许**某按钮（见上表），填了也不会显示；可在「备注」说明期望，我们可再讨论改逻辑。
