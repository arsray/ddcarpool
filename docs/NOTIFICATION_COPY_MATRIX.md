# Tab「消息」通知文案矩阵

> 与 `miniprogram/modules/notification/titles.js`、`cloudfunctions/order/common/notification-titles.js` 同步。  
> 聊天系统消息见 `miniprogram/modules/chat/system-events.js`（状态用词与主句一致）。

## 格式

**标题（单字段）** = `状态主句 · 补充 · 路线 · 出发时段`，中间用 ` · ` 分隔。

## 节点 × 角色

| 订单节点 | 乘车人 Tab | 车主 Tab | 标题模板（主句在前） |
|----------|:----------:|:--------:|----------------------|
| 司机接单 | ✅ | — | 订单已进入待出发 · {司机}已接单 · {路线} · {时段} |
| 乘客取消（已有司机） | — | ✅ | 订单已关闭 · 乘客已取消 · {路线} · {时段} |
| 司机取消接单 | ✅ | — | 订单重新匹配中 · 司机已取消匹配 · {路线} · {时段} |
| 行程自动开始 | ✅ | ✅ | 行程已开始 · {路线} · {时段} |
| 行程自动完成 | ✅ | ✅ | 行程已完成 · {路线} · {时段} |
| 匹配过期（窗结束仍 matching） | ✅ | — | 订单已关闭 · 匹配超时 · {路线} · {时段} |

## 不发送 Tab 通知

- 乘客发单、匹配中无司机时乘客取消、改人数（仅聊天系统消息）
- 无手工开始/结束行程（仅定时任务触发起止 + 上述通知）

## 入口

- **唯一入口**：底部 Tab「消息」（车主/乘车人分段）
- **已移除**：「我的 → 通知中心」（与 Tab 重复）
